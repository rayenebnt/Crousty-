# Protocole photo — Le Crousty

Le configurateur va assembler **de vraies photos de vos plats**, ingrédient par ingrédient : le pain, les tenders, le fromage avant et après le four, les sauces, les frites, les canettes. Pour que l'assemblage paraisse naturel, toutes les photos doivent être prises **de la même façon**.

Vous n'avez rien à détourer ni à retoucher : je m'en occupe (détourage automatique, recadrage, mise à l'échelle, compression).

La liste exacte des photos, avec le nom de chaque fichier, est dans [liste-des-photos.md](liste-des-photos.md).

## Le matériel

- **Un téléphone récent.** Pas besoin d'appareil photo.
- **De quoi tenir le téléphone à plat, toujours à la même hauteur.** Par exemple deux piles de livres de chaque côté avec une règle en travers, ou un petit trépied de table avec bras (≈ 15 à 25 €). C'est la condition la plus importante.
- **Un fond uni et mat, le même pour toutes les photos.** Idéalement gris moyen : une feuille de carton gris, un plan de travail gris, une table grise. Évitez le blanc brillant et les motifs.
- **Du ruban adhésif** pour marquer l'emplacement de l'aliment sur le fond.

## Les réglages du téléphone

- **Format JPEG.** Sur iPhone : *Réglages → Appareil photo → Formats → « Le plus compatible »*. Sur Android, c'est déjà du JPEG.
- **Pas de flash, pas de filtre, pas de mode Portrait.**
- **Objectif 2×** si le téléphone l'a (moins de déformation), sinon 1×. Le même pour toutes les photos.
- **Téléphone à l'horizontale** (mode paysage), pour toutes les photos.
- **Retardateur de 3 secondes** : le téléphone ne bouge pas quand on appuie.

## L'angle : vue de dessus, toujours la même

```
        📱  téléphone à plat, écran vers le haut
        │   à environ 40 cm, toujours la même hauteur
        │
        ▼
  ┌──────────────────────┐
  │   fond gris uni      │   ← l'aliment au centre,
  │      [ aliment ]     │     sur la marque de scotch
  └──────────────────────┘
```

- Le téléphone est **parallèle à la table**, exactement au-dessus de l'aliment.
- **Même hauteur pour toutes les photos d'aliments.** Seules les photos du plateau et de la feuille de journal se prennent de plus haut, pour qu'ils tiennent en entier.
- L'aliment est **entier dans l'image**, avec un peu de marge autour, jamais coupé par le bord.

## La lumière

- **Lumière du jour**, près d'une fenêtre, **sans soleil direct**. Les lumières de la salle peuvent rester allumées, mais toujours les mêmes.
- **Même endroit et même moment de la journée** pour toute la séance : les photos doivent avoir la même couleur.
- Évitez que votre ombre ou celle du téléphone tombe sur l'aliment : la lumière doit venir du côté, pas de derrière vous.

## Les aliments

- **Des portions réelles**, comme servies aux clients, avec une belle apparence : c'est ce que les clients verront.
- **Photographiez juste après la préparation** : fromage fondu, frites chaudes et brillantes, salade fraîche.
- Chaque ingrédient se photographie **seul**, disposé **en long comme dans le pain** (≈ 20 cm × 6 cm), sauf consigne contraire dans la liste.
- **Photos « même cadrage »** (fromage avant et après le four, frites puis frites nappées de cheddar) : ne bougez **ni le téléphone ni l'aliment** entre les deux photos. Pour le gratiné, remettez le sandwich exactement sur sa marque en sortant du four.
- **Sauces** : un filet en zigzag d'environ 20 cm, fait avec le flacon habituel, sur une assiette unie.
- **Canettes** : couchées, étiquette vers le haut.

## Nommer et envoyer les photos

1. **Nommez chaque photo** comme dans la liste (`tenders.jpg`, `gratin-fromage__avant.jpg`…). Le plus simple : prendre les photos **dans l'ordre de la liste**, puis les renommer sur un ordinateur.
2. **N'envoyez pas les photos dans cette discussion** : elles y sont compressées et perdent leur qualité.
3. **Déposez-les sur GitHub**, dans le dépôt du site :
   - ouvrez le dossier `photos/brutes` de la branche `claude/inspiring-ride-9trkdb` ;
   - cliquez sur **Add file → Upload files** ;
   - glissez les photos, puis cliquez sur **Commit changes**.
4. Dites-moi quand c'est fait : je lance le traitement et je vous montre le résultat.

## Droits et marques

- Les photos que vous prenez vous-même vous appartiennent. Si un photographe les prend, demandez-lui une **cession écrite des droits** pour le site.
- **Canettes** : sur de vraies photos, les logos des marques seront visibles. C'est courant pour montrer les boissons qu'on vend, mais dites-moi si vous préférez les masquer.
