# Photos brutes

Déposez ici les photos prises au restaurant, nommées comme dans
[`docs/photos/liste-des-photos.md`](../../docs/photos/liste-des-photos.md)
(par exemple `tenders.jpg`, `gratin-fromage__avant.jpg`).

Le protocole de prise de vue est dans [`docs/photos/protocole.md`](../../docs/photos/protocole.md).

Facultatif : un fichier `echelle.json` pour préciser l'échelle, par exemple
`{ "pxParCm": 38, "tailles": { "plateau-journal": 45 } }`
(`tailles` = longueur réelle du plus grand côté, en cm).
